# TGWR by IWS v0.2.1

Дата: 2026-07-15

Тип выпуска: patch pre-release

## Зачем нужен этот выпуск

TGWR 0.2.1 возвращает в распространяемое приложение слайд **«Команда и благодарности»**. В версии 0.2.0 файл Credits оставался в исходниках, но перестал подключаться к итоговой колоде после перехода от фиксированных 22 экранов к динамической истории.

Это не было ограничением приватности, производительности или платформы. Причиной стало неверное продуктовое решение: сокращение аналитической части заодно удалило экран авторства. Версия 0.2.1 отделяет лимит истории от обязательного Credits и закрепляет это автоматической проверкой.

## Что изменилось

- Credits снова подключён к динамическому deck builder;
- содержательная история ограничена максимум 14 экранами вместе с финальным экраном;
- Credits добавляется поверх этого лимита и всегда остаётся последним;
- один и тот же список используется обычным просмотром, Share Preview, PNG и PDF;
- Credits получил устойчивый DOM-маркер для release-smoke;
- synthetic browser smoke ожидает максимальную колоду из 15 экранов и завершает тест ошибкой, если последний экран не является Credits;
- версия приложения, worker, интерфейса, lock-файла и README синхронно повышена до 0.2.1.

## Что увидит пользователь

На насыщенном Telegram Export счётчик истории доходит до `15 / 15`, а последним открывается экран:

- создатель: **iwannasome**;
- продукт: **TGWR / Telegram Wrapped**;
- отдельный блок благодарностей людям, помогавшим идеями, обратной связью и поддержкой.

В коротком архиве общее число экранов может быть меньше 15: TGWR по-прежнему не создаёт пустые аналитические слайды. При любом размере истории Credits остаётся последним.

## Где присутствует Credits

| Путь | Результат |
|---|---|
| Просмотр Wrapped | обязательный последний экран |
| Клавиатурная навигация | клавиша End и переход вперёд доходят до Credits |
| Share Preview | Credits виден в точном предпросмотре публикации |
| PNG export | Credits записывается отдельным изображением в общей последовательности |
| PDF export | Credits становится последней страницей PDF |
| Windows/macOS/Linux packages | одинаковый renderer входит во все нативные сборки |

## Платформенные артефакты

Release workflow собирает приложение нативно на каждой поддерживаемой ОС:

| Платформа | Артефакт |
|---|---|
| Windows x64 | NSIS installer `.exe` |
| macOS Apple Silicon | ARM64 `.dmg` |
| macOS Intel | x64 `.dmg` |
| Linux x64 | `.AppImage`, `.deb`, `.rpm` |

PyInstaller worker также собирается отдельно на соответствующем runner. Благодаря этому пользователю готового приложения не требуется системный Python или Node.js.

## Проверки

Перед публикацией изменения проходят:

- TypeScript typecheck;
- production renderer build;
- security-smoke IPC и файловых границ;
- анонимизированные Python import fixtures;
- synthetic schema/metric contract;
- browser smoke всех 15 экранов максимальной колоды;
- явную DOM-проверку Credits в конце deck;
- desktop, mobile, empty и extreme состояния;
- навигацию, People, Share Preview и insight export;
- нативную package matrix для Windows x64, macOS x64/ARM64 и Linux x64;
- запуск приложения и bundled worker непосредственно из готового установщика, DMG или AppImage;
- SHA-256 ведомости для всех опубликованных файлов.

## Приватность

Исправление не меняет архитектуру обработки Telegram Export. Исходные сообщения, локальная SQLite-база и `report.json` не загружаются в сеть. Share Preview по-прежнему позволяет скрыть имена, текст сообщений и точные даты перед публикацией.

Credits содержит сведения об авторстве TGWR и благодарности участникам проекта. Он не извлекает имена из пользовательского Telegram Export и поэтому не проходит через псевдонимизацию собеседников.

## Установка и доверие ОС

TGWR распространяется напрямую через GitHub Releases. Если Windows и macOS artifacts собраны без коммерческой подписи издателя, выпуск остаётся **Pre-release**:

- Windows SmartScreen может показать неизвестного издателя;
- macOS Gatekeeper может потребовать подтверждение в разделе «Конфиденциальность и безопасность»;
- Linux AppImage может потребовать ручное разрешение на запуск.

Скачивай TGWR только со страницы Releases этого репозитория и сверяй файлы с общей `SHA256SUMS.txt`. Предупреждение ОС нельзя игнорировать для копии, полученной из чата, облачного диска или стороннего сайта.

## Обновление с 0.2.0

0.2.1 является совместимым patch-релизом. Формат `tgwr.db` и схема `report.json` не меняются, поэтому повторный Telegram Export или полный сброс данных не требуется. После установки новой версии можно открыть существующий отчёт и перейти к последнему слайду.
